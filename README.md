# A Day of One-Line Pitches

make.fun bounty `u-ronigrv-a-day-of-one-line-pitches-12cd9bb3` (program/v1).

One sentence to a friend who has never coded: describe the app idea in plain words and an AI agent builds a real first version today — free to try, no code needed, and the idea stays yours.

## Entry

```
Just describe your app idea in plain words and an AI agent on make.fun will build you a real, working first version today — free to try, no code needed, and the idea stays yours.
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
